Privacy Policy – yt-analytics

Last updated: 2026-11-10

What the tool accesses

With the account holder's consent, yt-analytics requests read-only access to YouTube channel data (scopes youtube.readonly and yt-analytics.readonly): video lists and channel statistics such as views, watch time and audience retention.

How the data is used

The data is read on the owner's own computer to review the performance of the owner's own channels. It is not sold, not shared with third parties and not used for advertising.

Storage

Authorization tokens and downloaded statistics are stored only on the owner's computer. No data is sent to any server operated by this tool.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the local token files removes all stored authorization.

Contact

Questions can be raised through the issue tracker of this page's GitHub repository.
